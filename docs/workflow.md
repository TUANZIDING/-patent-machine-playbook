# 工作流说明

![六步进攻路线](../assets/playbook.jpg)

## 为什么这样分工
- **patent-disclosure-skill** 擅长中文专利语境：挖点、国知局查新、交底书模板、Word 输出、审查答复。
- **machine-skill** 擅长把结构变成可拆解、可剖切、跑真实物理公式的 3D 模型，给「技术效果」提供可解释的量化依据。
- **本仓库** 只做调度和规则，避免两个技能各写各的。

## 三条红线
1. **提前公开**：中国专利以申请日判断新颖性，宽限期只适用于少数法定情形（如指定展会、学术会议首次发表等），自己发视频或网页不在其中。
2. **疾病诊疗方法**：专利法第 25 条排除，医疗创新写成装置 / 系统。
3. **仿真冒充实验**：审查与后续维权都看证据，仿真只作辅助。

## 适用 / 不适用
- 适用：器械结构改进、机电装置、带算法的监测系统、工装夹具。
- 不太适用：纯药物配方、纯生物机制（machine-skill 无法建模，可只用 patent-disclosure-skill）。
